# Triveni Turbine – Job Opportunities

Responsive React JS implementation based on the supplied web-flow reference.

## Included

- Responsive Careers / Job Opportunities page
- Reusable `Header`, `JobCard`, `JobDetails`, `Field`, `ApplicationPage`, and `SuccessPage` components
- React functional components and hooks
- React Router-compatible navigation
- Job details modal
- Apply Now flow with selected job automatically carried into the application
- Frontend validation for:
  - Full name
  - Email
  - Indian 10-digit phone number
  - Resume required/type/5 MB size
  - Cover letter/message
- Successful submission confirmation screen
- Responsive desktop/tablet/mobile CSS
- No horizontal scrolling on normal supported viewport sizes
- Backend/API-ready submission point in `ApplicationPage`
- Outlook/Gmail/Apple Mail-friendly table-based HTML email template in `email/job-application.html`

## Run

```bash
npm install
npm run dev
```
